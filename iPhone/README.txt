PC Pulse v0.1 — iPhone App
===========================

This folder contains the SwiftUI source for a REAL iPhone app.

What it does
------------
- Has its own app icon/app container once built.
- Scans the QR generated by the Windows PC Pulse server.
- Stores the paired PC address/token.
- Refreshes every 1.5 seconds.
- Shows CPU, RAM, storage, uptime, PC name.
- Can forget/re-pair the PC.

Build requirement
-----------------
Apple's normal iOS build step requires Xcode/macOS somewhere.

Easiest build flow if you only own Windows:
1. Upload this iPhone source to a macOS CI/build service that supports Xcode.
2. Generate/open the Xcode project (project.yml is included for XcodeGen).
3. Build/export the .ipa.
4. Sign/install the IPA using a valid Apple signing method you own.

XcodeGen flow on macOS
----------------------
1. Install Xcode + XcodeGen.
2. In this iPhone folder:
       xcodegen generate
3. Open PCPulse.xcodeproj.
4. Set your Apple Development Team / bundle ID.
5. Build to your iPhone or export an IPA.

HTTP local-network note
-----------------------
PC Pulse intentionally uses plain HTTP on your private LAN.
Info.plist includes:
- NSLocalNetworkUsageDescription
- NSAllowsLocalNetworking

No local CA certificate is needed just to view CPU/RAM/storage.

PC Pulse v0.1 — Windows Server
================================

1. Double-click START_PC_PULSE.bat.
2. Allow Python through Windows Firewall on PRIVATE networks if asked.
3. Keep the window open.
4. A QR image appears.
5. The iPhone app scans that QR and stores the PC server + pairing token.

The server exposes:
- CPU %
- RAM usage
- Windows drive usage
- PC name
- uptime

The QR contains a random token created each time the server starts.
